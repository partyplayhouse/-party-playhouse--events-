# Party Playhouse & Events Website

This folder is ready to publish with GitHub Pages.

## Publish on GitHub
1. Create a GitHub account if you don't already have one.
2. Create a new repository named `party-playhouse-events`.
3. Upload everything inside this folder, keeping the `assets` folder intact.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. GitHub will give you a public website address.
